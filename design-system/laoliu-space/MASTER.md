# laoliu.space 设计规范

更新日期：2026-10-31。全站沿用已确认的首页风格。本文件替代旧的水墨设计规范。

## 视觉方向

- 采用都市忧郁风。深蓝灰色用于导航和页面介绍，暖灰纸色用于作品、文章和自述正文。
- 场景保留左侧雨夜城市窗景、书桌、电脑、咖啡和笔记本。室内只有一盏暖色台灯，不出现人物。
- 场景保持清晰，不增加整幅模糊、浮动光斑或玻璃卡片。
- 正文事实与文章内容沿用现有数据，不为视觉改造虚构经历或项目。

## 颜色

变量定义在 `src/styles/site.css`。

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--night` | `#1b2835` | 导航、首页和页面介绍背景 |
| `--night-soft` | `#243442` | 深色辅助背景 |
| `--paper` | `#eeede7` | 内容背景 |
| `--paper-soft` | `#e5e5dd` | 引文、表头背景 |
| `--ink` | `#303940` | 正文 |
| `--muted` | `#687376` | 日期、说明和次级文字 |
| `--warm` | `#bda181` | 按钮、细节和阅读进度 |
| `--line` | `#30394026` | 内容分隔线 |

## 字体与尺寸

- 中文标题采用宋体，英文标题采用 Georgia。正文采用 Arial 和微软雅黑。代码采用 Consolas。
- 使用系统字体，避免外部字体请求影响加载。
- 常规文字尺寸为 11、13、16、20 像素。文章正文在电脑上为 17 像素，手机上为 16 像素。
- 页面标题在电脑上为 36 到 58 像素，手机上为 38 像素。首页标题按首屏构图单独调整。
- 间距以 8、16、24、32、48、64、96 像素为主。
- 页面最大宽度为 1240 像素。电脑两侧至少留 56 像素，平板留 32 像素，手机留 20 像素。
- 文章正文最大宽度为 760 像素。电脑显示侧边目录，手机把目录放在正文前。
- 项目列表在电脑上分三列，平板分两列，手机分一列。

## 公共布局

- `Base.astro` 负责导航、页脚、音乐和基础样式。
- 导航统一为首页、作品、文字、自述。手机直接显示四个链接。
- 首页使用完整场景。其他页面通过 `PageIntro.astro` 显示标题和缩小的同一场景。
- `ProjectCard.astro` 和 `ArticleCard.astro` 同时服务首页与列表页，保持一致的卡片和文章行。
- 代码块与宽表格在自身区域横向滚动，页面整体不横向溢出。

## 动效与交互

- 雨滴和咖啡热气由 `DeskScene.astro` 持续播放。
- 用户明确要求移除暂停动效与台灯开关。场景不显示这两类按钮，台灯保持开启。
- 场景滚出视口时继续播放。浏览器标签页隐藏时暂停绘制，重新显示时继续。
- 用户明确要求所有场景动效持续显示。因此，系统的减少动态效果设置不隐藏雨滴或热气。
- 系统的减少动态效果设置仍取消文字入场、滚动显现和悬浮过渡。
- 常规内容只在进入视口时轻微上移并显现一次。键盘聚焦内容时立即显示。
- 悬浮反馈限于链接箭头、卡片边框和按钮颜色。触屏无需悬浮即可使用。
- 音乐由用户点击“听一会儿”播放，不自动播放。页面跳转会重新加载音乐控件。
- 保留跳过导航入口、键盘焦点描边和无脚本时可读的正文。

## 场景素材

- 电脑：`public/art/urban-bedroom-empty-v5.webp`。
- 手机：`public/art/urban-bedroom-empty-v5-mobile.webp`。
- 原图与生成提示保留在同目录的 `.png` 和 `.prompt.txt` 文件。
- 雨滴位置与热气位置依赖当前画面中的窗户与杯子。更换图片时，需要同时校准动效位置。

## 验证

- 类型检查：`npm run check`。
- 单元测试：`npm test`。
- 生产构建：`npm run build`。
- 浏览器检查脚本：`tests/home-motion.browser.js`。覆盖公共页面、手机宽度、持续动效、文章入口、目录与无脚本阅读。
