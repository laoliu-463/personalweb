> 这是一篇示例文章，用来演示格式。网站搭好后可以删掉它，写你自己的第一篇。

## 为什么要做这个站

一个放文章和项目的地方。域名和托管以后再说，先把内容架子跑起来。

## 这里怎么运转

- 文章放在 `src/content/blog/` 下的 `.md` 文件里
- 项目列表构建时自动从 GitHub 拉取
- 本地预览：`npm run dev`

## 写新文章

新建一个 `.md` 文件，开头写上标题、描述和日期，剩下的就是正文。保存后浏览器自动刷新。
