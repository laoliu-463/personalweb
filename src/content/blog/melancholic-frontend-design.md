现代 Web 设计正在陷入一种可怕的趋同：圆角卡片、高饱和度渐变、无处不在的微动效。它们看起来极其专业、高效、充满朝气，却没有任何温度。

真实的人类情绪并不总是阳光明媚的。在漫长的工作重压、夜深人静的代码重构、对技术迭代的迷茫中，**焦虑**与**忧郁**是几乎每一个开发者都难以回避的常态。

## 调色板的第一性原理

我们为什么选择 `#0a0a0f` 而不是纯黑 `#000000`？

1. **纯黑是虚无，深蓝黑是夜空**：`#0a0a0f` 带有微弱的冷蓝底色，它不是绝对的深渊，而是带有温度的残存光照。
2. **文字的褪色感**：选择 `#8a8a9a` 作为主文本，降低对比度，正如旧书籍上因氧化而泛黄的铅字，不刺眼，像快要隐去的记忆。
3. **暗血红 `#c9375c` 的伤口隐喻**：只有在关键交互或警示时，暗红色才会浮现。它不是为了诱导点击，而是一记刺痛。

## 动效的焦虑隐喻

### 8秒呼吸周期
```css
@keyframes body-breathe {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.975; }
}
```
8秒是一个人深度呼吸的平均时间。页面并不静止，它在伴随访客一同呼吸。

### 不规则颤抖（Jitter）
当鼠标悬停在链接上时，文字不会轻浮地放大，而是产生极细微的抖动：
```css
@keyframes jitter {
  0% { transform: translate(0, 0); }
  25% { transform: translate(-0.8px, 0.8px); }
  50% { transform: translate(0.8px, -0.6px); }
  75% { transform: translate(-0.6px, -0.8px); }
  100% { transform: translate(0, 0); }
}
```
这种微震颤模仿了神经紧绷时的手指抽搐，带来一种真实的不适感与沉浸感。
